用文字畫一隻會游的金魚

2026-11-09 Note · Tutorial 看完整的金魚池 ↗

ASCII 金魚看起來很複雜，其實只是幾個小觀念一層一層疊上去。這篇把它拆成八步，每一步都有一個可以直接玩的小範例：滑鼠移到範例上就會跟著你，拖拖看下面的滑桿，數字一改，馬上就知道那個參數在做什麼。

整隻魚只有四層，由下往上疊：

④ 互動 點一下 → 水波，點兩下 → 飼料 ③ 外觀 顏色、色磚、鱗片、眼睛 ② 身體 一條「脊椎」決定魚在哪、彎成什麼樣子 ① 舞台 一張字元方格紙 + 每秒重畫 60 次

最重要的一個觀念：「動」和「畫」是兩件事。每一幀先算出魚現在在哪、長什麼樣子，再把結果「印」到方格紙上。這兩件事分開，程式才不會亂。

01會動的點

網頁動畫的核心只有一個迴圈：清掉畫面、算新位置、再畫一次，一秒重複約 60 次。requestAnimationFrame 會在瀏覽器準備好下一幀時呼叫你的函式。

移動的距離要用「速度 × 經過的時間」來算，也就是程式裡的 dt。這樣不管電腦快或慢，點都用一樣的速度前進。

let last = performance.now();
function loop(now) {
  const dt = (now - last) / 1000;  // 兩幀之間過了幾秒
  last = now;
  x += speed * dt;                 // 距離 = 速度 × 時間
  draw();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

02一張字元方格紙

把畫面切成一格一格，每一格放一個字元。每一幀先把所有格子的內容寫進一張表（陣列），最後再一次全部畫到畫面上。

這裡每一格都量一下自己離滑鼠多遠：越近，字元越「重」（. : o @）。改字元大小，整張紙就重新排一次。

移動滑鼠看看
for (const cell of grid) {
  const d = distance(cell, mouse);
  cell.char = d < 24 ? '@' : d < 48 ? 'o' : d < 76 ? ':' : '.';
}

03會跟著走的鍊條

做一串點：第一個點（頭）追著滑鼠，其他每個點只做一件事：跟著前一個點，保持固定距離。不用寫任何「怎麼擺動」的程式，鍊條就會自己彎得很自然。金魚的脊椎就是這條鍊。

for (let i = 1; i < points.length; i++) {
  const a = points[i - 1], b = points[i];
  const dir = normalize(b - a);      // 從前一個點指向自己
  points[i] = a + dir * gap;         // 拉回固定距離
}

04讓鍊條長出身體

有了脊椎，再決定「每一段有多胖」：頭圓、中間最胖、尾巴細，就是一張寬度表。接著每一格只問兩個問題：

  1. 我離脊椎上的哪一點最近？那一點在身體的第幾 %？（叫它 u，嘴巴是 0，尾巴開始的地方是 1）
  2. 我在脊椎旁邊多遠？

只要「多遠」小於那一段的寬度，這格就屬於魚身。打開下面的 Show u，每一格會直接顯示它的 u（0–9）。之後的鱗片、眼睛、肉瘤、花紋，全部都是看這兩個數字決定的。這招叫局部座標，是整個專案最關鍵的一招。

const { u, side } = nearestPointOnSpine(cell);
if (side < width(u)) cell.char = '*';   // 在身體裡面

05讓魚自己游

不再追滑鼠了：魚每次挑一個隨機的目標點（畫面上的 x），游過去，到了再挑下一個。重點是轉彎速度有上限。「想去哪」和「實際怎麼轉」是兩回事，限制轉彎速度，動作才會像生物。

第二個滑桿是我們真的踩過的坑：鍊條每一節最多能彎幾度。把 Max bend 拉到最大、Turn 也拉高，看魚急轉彎時身體會從中間「折斷」。金魚很胖，彎得太急，內側的格子就分不清屬於前段還是後段。把每節限制在幾度以內，就修好了。

const want = angleTo(target);
angle += clamp(want - angle, -turnSpeed * dt, turnSpeed * dt);  // 一次只轉一點點

06鰭和尾巴：慢半拍的線

尾巴是很多條小鍊條，根部黏在身上。每條線的每一點，都朝「它該在的位置」移動，但越往末端越慢半拍，飄逸感就是這樣來的。畫的時候，看每一小段線往哪個方向，就挑 - / | \ 其中一個字元。

試試把 Rigid root 關掉：根部也開始慢半拍，魚一轉彎，整片尾巴就被甩離身體。這也是我們實際遇到的 bug：哪些地方要硬接、哪些地方可以飄，要分清楚。

Follow 越小，尾巴越飄 
const follow = rootIsRigid && nearRoot ? 1 : lag * (1 - 0.7 * q);  // q：0 根部 → 1 末端
p.x += (target.x - p.x) * follow;

07上色：一條漸層、一層色磚

顏色只用一條漸層：紅 → 橘 → 白。每一格只要記一個 0 到 1 的數字，代表在漸層上的位置；換主題的時候，只要換掉這條漸層。

身體每一格先墊一塊色磚，字元用深一點的同色畫在上面；鱗片就是交錯排列的 (((。把下面兩個開關切來切去，看看各自負責什麼。

08互動和氣氛

最後一層：點一下，用 cos 做出一圈亮、一圈暗往外擴散的水波；點兩下撒飼料，魚的目標從隨機點換成最近的飼料。每隻魚再往右下方複製一份淡灰的自己，就是陰影。下面就是完整的金魚池，點點看。

+會用到的數學

只要這幾個，而且不用先學完，遇到再學就好：

工具白話在哪用
(x, y) 向量一個方向加一段距離魚往哪游
Math.atan2從方向算出角度轉向、挑線條字元
cos / sin從角度算回方向；也能做規律的波動擺尾、水波
lerp從 A 慢慢靠近 B速度變化、鰭慢半拍
smoothstep讓變化的頭尾都很柔和身體輪廓、淡出

+從 bug 學到的三件事

  1. 魚身骨折：鍊條可以彎太急 → 學會「限制條件」，每一節最多彎幾度。
  2. 尾巴跟身體分開：根部也在慢半拍 → 分清楚哪些要硬接、哪些可以飄。
  3. 尾柄看起來重複：身體、補丁、尾巴三套東西畫在同一個地方 → 一個區域只讓一個系統負責。最後的解法是身體只畫前 3/4，剩下的交給尾巴。

兩個除錯小習慣：做一個「暫停模式」，讓魚停住，才看得清楚形狀；還有用數字確認，不要只靠眼睛。我一度以為魚不吃飼料，量了牠們的位置才發現其實沒問題。
